# Function Grapher

Explore mathematical functions from a memory model. Choose a function and a variable, set its range and step, and adjust the other parameters to compare curves. Output checkboxes show or hide individual curves.

## Run locally

Install [mise](https://mise.jdx.dev/getting-started.html), then run:

```sh
mise install
mise run setup
mise run dev
```

Open the URL printed by Vite.

## Development

Run `mise run verify` before committing. Local Git hooks and CI run the same checks.

- [Development](docs/development.md): setup, commands, tests, and adding functions.
- [Architecture](docs/architecture.md): ownership, dependencies, contracts, and sampling behavior.
